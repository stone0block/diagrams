# site: сайт и MCP-сервер

Публичный репозиторий (решение владельца): секретов в коде нет, чужой код и шрифты только по их лицензиям. Cloudflare Workers + база D1. Название и домен рабочие, настоящие выбираются на Этапе 1 (см. `../../Планирование/Этапы.md`).

## Что здесь

| Путь | Что |
|---|---|
| `src/index.ts` | Маршруты: `/mcp` (MCP-сервер), `/d/<id>` (страница-редактор), `/` (лендинг, `?example=` выбирает образец в форме), `/demo` (образец схемы без записи в базу), `/new` (форма лендинга), `/healthz`. Политика безопасности (CSP): строгая, для редактора чуть шире (воркер и WebAssembly для шрифтов) |
| `src/mcp.ts` | Инструмент `save_diagram` |
| `src/validate.ts` | Проверка входных данных и лимиты (код до 50 000 символов, название до 200) |
| `src/store.ts` | Запись и чтение схем, суточный потолок записей |
| `src/pages.ts`, `public/style.css`, `public/favicon.svg` | Страницы и всё оформление: лендинг, «не найдено», шапка редактора, сетка точек холста. Стиль, логотип и иконки свои, шрифты системные |
| `editor/` | Редактор: React + готовый Excalidraw (MIT) + mermaid-to-excalidraw. Превращает Mermaid-код в блоки на холсте (цвета блоков, угловые стрелки для flowchart), правки хранит в браузере, экспорт PNG/SVG с водяным знаком |
| `scripts/build-editor.mjs` | Собирает редактор в `public/editor/` (в git не попадает): бандл, шрифты, `licenses.txt`. Два патча чужого кода при сборке: запасной адрес шрифтов Excalidraw (esm.sh) на наш домен; id блоков Mermaid без префикса, иначе ER, class и подграфы приходят картинкой. Если патч перестал подходить, сборка падает |
| `public/editor-config.js` | Путь к шрифтам Excalidraw. Должен грузиться до бандла |
| `third-party/` | Текст лицензии Excalidraw (в npm-пакете его нет), попадает в `licenses.txt` |
| `migrations/` | Схема базы |
| `test/` | Тесты проверки входных данных и id |

## Запуск локально

```bash
npm install
npm run dev
```

`npm run dev` сначала собирает редактор (`npm run build:editor`). После правок в `editor/` пересобери его той же командой.

Откроется на http://localhost:8787. Аккаунт Cloudflare для локального запуска не нужен.

## Проверки

```bash
npm run typecheck
npm test
```

## Где менять имя и домен

- Имя на страницах: `src/brand.ts`.
- Адрес в ссылках от `save_diagram`: переменная `PUBLIC_BASE_URL` в `wrangler.jsonc` (пусто = адрес запроса).
