# site: сайт и MCP-сервер

Приватный репозиторий. Cloudflare Workers + база D1. Название и домен рабочие, настоящие выбираются на Этапе 1 (см. `../../Планирование/Этапы.md`).

## Что здесь

| Путь | Что |
|---|---|
| `src/index.ts` | Маршруты: `/mcp` (MCP-сервер), `/d/<id>` (просмотр схемы), `/` (заглушка), `/healthz` |
| `src/mcp.ts` | Инструмент `save_diagram` |
| `src/validate.ts` | Проверка входных данных и лимиты (код до 50 000 символов, название до 200) |
| `src/store.ts` | Запись и чтение схем, суточный потолок записей |
| `src/pages.ts`, `public/` | Страницы и скрипт просмотра. Mermaid отдаётся с нашего же домена |
| `migrations/` | Схема базы |
| `test/` | Тесты проверки входных данных и id |

## Запуск локально

```bash
npm install
npm run dev
```

Откроется на http://localhost:8787. Аккаунт Cloudflare для локального запуска не нужен.

## Проверки

```bash
npm run typecheck
npm test
```

## Где менять имя и домен

- Имя на страницах: `src/brand.ts`.
- Адрес в ссылках от `save_diagram`: переменная `PUBLIC_BASE_URL` в `wrangler.jsonc` (пусто = адрес запроса).
